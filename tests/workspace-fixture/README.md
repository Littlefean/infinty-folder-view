# 空间代码阅读器

这个目录用于检查 **嵌套文件夹**、Markdown、代码和纯文本的混合展示。

## 试一试

1. 拖动 `src` 标题，整个目录一起移动。
2. 把一个文件推向另一个文件，观察碰撞推挤。
3. 拖选代码并按 `⌘C`，确认缩进和换行保留。
4. 点击目录标题后按 `A`，整理这个目录。

```rust
let canvas = Canvas::new();
canvas.open("./project");
```

| 类型 | 阅读方式 |
| --- | --- |
| Markdown | 富文本 |
| 代码 | 语法高亮与行号 |
| 纯文本 | 保留原文 |
